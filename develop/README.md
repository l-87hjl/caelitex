# develop/ — incubation zone

**This directory is non-canonical by design.** Material here:

- is allowed to be incomplete;
- is allowed to contradict itself;
- is allowed to be speculative;
- is allowed to stay here indefinitely.

**Everything *outside* `develop/`** must serve a stable purpose, and must be
explainable from [`README.md`](../README.md) as part of the project.

Nothing graduates out of `develop/` merely because it has been here a while. It
graduates when it becomes structurally meaningful — and, if it resolves something,
when the corresponding entry in [`OPEN-QUESTIONS.md`](../OPEN-QUESTIONS.md) is
recorded as resolved.

**This is a public repository.** "Non-canonical" means *not authoritative*; it does not
mean *not published*. Do not put anything here that should not be world-readable.

It is empty at bootstrap. That is expected.
