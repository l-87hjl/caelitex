# Glossary

Vocabulary is cheap to fix and expensive to fix wrongly. Terms below are marked either
**settled** or **deliberately open**.

| Term | Meaning | Status |
|---|---|---|
| **CAELITEX** | The project and this repository. From "caeli" (of the heavens / sky) + Latin *texere* (to weave). | **settled** |
| **Caeliform** | Retained project vocabulary and conceptual terminology. Possible eventual uses include *Caeliform framework*, *representation*, *model*, *signature*. | **deliberately open** — see below |
| **Structure** | A collection of astronomical objects treated together. **Not** a synonym for a traditional Earth constellation. | **settled negatively**: what it is not is fixed; the grouping strategy is **OQ-21**. |
| **Representation** | Any transformation of the underlying information — mathematical, machine-readable, statistical, visual, symbolic. Separable from source data and from models. | **settled** |
| **Signature** | A representation intended to identify a structure. Which mathematical form is **OQ-18**. | term settled, content open |
| **Glyph** | A visual / symbolic rendering derived from intrinsic relationships. **A glyph is not the underlying identity.** | **settled negatively**; the algorithm is **OQ-17**, and whether glyphs are pursued at all is open. |
| **Recognition horizon** | How far in space, and how far forward or backward in time, a reference's identity remains recoverable. | term settled, measurable content is **OQ-40** |
| **Reference class** | A category of object used as a navigational or identifying reference — ordinary stars, stellar groups, pulsars, globular clusters, galaxies, quasars, others. | **settled** |
| **Transform** | An interchangeable stage in the pipeline. The interface is **OQ-13**. | term settled, interface open |
| **Permitted / withheld** | The record of which information a transform could use and which properties were held back. | **settled** — see [`scientific-discipline.md`](scientific-discipline.md) |

## On "Caeliform"

**Caeliform is deliberately not given a rigid technical definition, and giving it one is
not a tidying-up task.** It is retained as vocabulary because the concept it gestures at
may turn out to be the useful one — a family of representations, a particular
transformation, a signature format — and which of those it becomes depends on research
that has not happened.

**Caeliform is not a separate repository at this stage.** The repository is CAELITEX.
Tracked as **OQ-44**.

## Words used with narrower meaning than usual

- **Invariant** — invariant *with respect to a named transformation*. An unqualified
  "invariant representation" is an incomplete statement; see
  [`research-directions.md`](research-directions.md) §1.
- **Discovery** — a validated relationship, not an interesting-looking pattern. See
  [`scientific-discipline.md`](scientific-discipline.md).
- **Rotor machine / loom** — used **only** as an architectural analogy for interchangeable
  composable stages. **No cryptographic claim, property or intent is implied.**
